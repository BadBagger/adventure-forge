# Department Character Model Sheets

Canonical identity references for Department of Impossible Complaints animation
work in Adventure Forge.

These sheets are the new first gate for animation. Motion strips should be
generated from these model sheets, not from text description alone.

## Files

- `mara-vane-model-sheet-v1.png` — approved first-pass identity lock for Mara.
  Strong consistent coat, satchel, boots, face, side/back reference, and
  expression row. Background is still slightly generated/gradient, so use as
  identity reference first; clean/key separately before slicing any cells from
  this sheet.
- `quire-model-sheet-v1.png` — approved first-pass identity lock for Quire as a
  counter-window actor. The sheet solves the key design problem: hands, pen,
  stamp, paperwork, and counter edge are designed together instead of pasted
  separately. Future strips must keep this counter baseline and hand attachment.
- `pigeon-model-sheet-v1.png` — approved first-pass identity lock for the
  perched department pigeon. Perch/contact consistency is the important rule.
  The drawn wing-motion marks are reference-only and should not appear in final
  animation strips.
- `dill-model-sheet-v1.png` — approved first-pass identity lock for Dill. Strong
  anxious technician silhouette and expression range for Chapter 2.

## Model-consistency gate

Reject any generated strip if it changes:

1. face shape or apparent age;
2. body proportions or character height;
3. outfit shapes, color palette, key props, or silhouette;
4. foot/contact baseline;
5. counter/perch/window relationship for non-standing actors.

Animation can exaggerate motion. It cannot re-cast the character.
